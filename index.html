☁️ Conectar Banco de Dados Online (Firebase)

Para você e seu amigo acessarem e editarem juntos de casas diferentes (hospedado no GitHub Pages):

  1. Acesse console.firebase.google.com (gratuito) e crie um projeto.
  2. No menu lateral, vá em Criação > Firestore Database e clique em Criar banco de dados (inicie no Modo de teste).
  3. Vá em Configurações do Projeto (⚙️) > Seus aplicativos > Web (</>) e copie o objeto firebaseConfig.
